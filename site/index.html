Steading packages

Signed Fedora packages for every Steading component.

Install

sudo dnf install https://pkgs.stead.ing/steading-release.noarch.rpm
sudo dnf install skift

steading-release adds the repository and its signing key. Or add the repository alone:

sudo dnf config-manager addrepo --from-repofile=https://pkgs.stead.ing/steading.repo

Channels

stable is enabled by default. It moves to the newest edge build that has been in edge for at least 48 hours and hasn't been yanked. To follow edge, which gets every release as soon as it is published:

sudo dnf config-manager setopt steading.enabled=0 steading-edge.enabled=1

Each component's promotion history is at /channels/<component>.json, for example skift.json.

Signing key

Every package, and every channel's metadata, is signed with this key. dnf checks both.
